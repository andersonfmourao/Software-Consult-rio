Sistema web para consultório odontológico.

Diretrizes do projeto:
- interface em português do Brasil
- design profissional e minimalista
- login obrigatório em todas as áreas internas
- agenda de consultas
- cadastro de pacientes
- prontuário e histórico clínico
- documentos anexados por paciente
- segurança e organização para produção (boas práticas LGPD)

Stack obrigatória:
- Next.js
- TypeScript
- Prisma
- PostgreSQL
